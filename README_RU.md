# CPM RP — Expansion 2.0 (тестовый режим)

## Что это

Пакет добавляет в существующий aiogram-бот единый модуль `rp_expansion.py` с командами для 16 направлений: политика и парламент, динамическая экономика, медицина, 911/диспетчерская, сезоны и события, семьи/брак/наследство, цены автомобилей, суд, автомобильные клубы, долги/банкротство, новости/ТВ, государственные тендеры, недвижимость/аренда, акции и достижения.

**Важно:** на этом этапе все новые команды работают в отдельной песочнице `rp_demo_*`. Они не списывают и не начисляют деньги в настоящем `users.balance`, не меняют реальные автомобили, бизнесы, квартиры и прочие активы. Это сделано специально, чтобы можно было проверить механику без риска для текущих игроков.

## Файлы

- `bot.py` — обновлённый бот на основе переданного `bot(9).py`; подключает новый Router и разрешает команды тестового режима в личных сообщениях.
- `database.py` — исходный `database(8).py`, без удаления или переименования таблиц.
- `rp_expansion.py` — новый модуль и отдельные таблицы `rp_demo_*` в той же SQLite-базе.
- `test_expansion.py` — проверка схемы и повторного запуска миграции.
- `bot.py.original`, `database.py.original` — исходники для сравнения и отката.

## Установка в отдельной тестовой копии

1. **Не устанавливай поверх работающего бота сразу.** Скопируй всю папку проекта в отдельную папку, например `CPM_RP_TEST`.
2. Скопируй в неё свой действующий `config.py`. Не вставляй токен в переписку и не публикуй его в GitHub.
3. Замени в тестовой папке `bot.py` и `database.py` файлами из архива. Добавь `rp_expansion.py` рядом с ними.
4. Сохрани резервную копию `bot.db`. Тестовая копия должна использовать свою копию базы, а не рабочую базу сервера.
5. Установи те же зависимости, что нужны исходному проекту (в первую очередь ту же совместимую версию aiogram 3 и зависимости, которые уже использует бот).
6. Запусти `python bot.py` из папки тестового проекта.
7. Открой личные сообщения с ботом и отправь `демо`.
8. Отправь `команды` — бот покажет полный список. Все новые команды вводятся обычными русскими словами, без `/` и подчёркиваний.

Не запускай две копии одного Telegram-бота с одним токеном одновременно: Telegram будет конфликтовать за polling. Для безопасного теста используй отдельного тестового бота и отдельный токен в тестовом `config.py`.

## Быстрый запуск теста

`python test_expansion.py`

Тест проверяет создание 26 таблиц песочницы, стартовые справочные данные и идемпотентность инициализации. Он не заменяет полноценный запуск Telegram-бота: для этого нужны твой `config.py`, установленный aiogram и остальные зависимости исходного проекта.

## Команды

Вводить без слеша и без подчёркиваний. Единственная команда для просмотра полного списка — `команды`.

- `команды` — полный список.
- `рп` — меню систем.
- `демо` — включить тестовый профиль.
- `обычный режим` — выключить тестовый профиль.
- `выборы`, `кандидат ТЕКСТ`, `голос UID`, `парламент`, `завершить выборы`.
- `экономика`, `автоцены`, `автоцена ID`, `купить авто ID`, `обновить рынок`.
- `биржа`, `купить акции КОД КОЛИЧЕСТВО`, `продать акции КОД КОЛИЧЕСТВО`.
- `вызов СКОРАЯ ОПИСАНИЕ`, `вызов ПОЛИЦИЯ ОПИСАНИЕ`, `вызов ПОЖАРНЫЕ ОПИСАНИЕ`, `вызовы`, `принять вызов ID`, `закрыть вызов ID`.
- `медкарта`, `больница`, `выписка`.
- `семья создать НАЗВАНИЕ`, `семья вступить ID`, `семья информация ID`.
- `брак UID`, `принять брак ID`, `завещание UID`, `смерть`, `наследство`, `получить наследство`.
- `иск UID ОПИСАНИЕ`, `суды`, `решение ID ТЕКСТ`.
- `клуб создать НАЗВАНИЕ`, `клуб вступить ID`, `клуб информация ID`.
- `кредит СУММА`, `погасить СУММА`, `банкротство`.
- `новости`, `опубликовать новость ЗАГОЛОВОК | ТЕКСТ`, `телевидение`.
- `сезон`, `события`, `участвовать ID`, `достижения`.
- `тендеры`, `заявка ID СУММА`, `выдать тендер ID UID`.
- `недвижимость`, `купить недвижимость ID`, `сдать недвижимость ID СУММА`, `арендовать ID ДНИ`.

Административные действия доступны только администраторам. Все суммы и активы остаются тестовыми.

## Ограничения текущего прототипа

- Все новые игровые действия — демонстрационные; они не интегрированы в боевой баланс и настоящие таблицы активов.
- Рынок обновляется командой администратора `/market_refresh`, а не по таймеру.
- Выборы закрывает администратор командой `/election_close`; автоматического календаря выборов пока нет.
- Судебные решения и выдача тендеров — ручные действия администратора.
- Система достижений пока содержит базовое достижение за вход; дополнительные условия и награды можно расширить.
- Наследование демонстрирует передачу тестовых денег, автомобилей и недвижимости; юридические ограничения/налоги и сложные семейные связи пока не моделируются.
- Брак, клубы, семьи, вызовы и суд требуют, чтобы второй участник также создал тестовый профиль командой `/rp_demo`.
- Telegram-команды не дают физического управления Car Parking Multiplayer: это RP-учёт и сценарии внутри Telegram.

## Важное перед следующим этапом

После тестирования можно будет подключать выбранные системы к реальному балансу по одной, начиная с транзакций и аудита. Не подключай сразу фондовый рынок, кредиты, аренду и налоги к реальным деньгам без отдельного тестирования всех сценариев и резервной копии БД.
